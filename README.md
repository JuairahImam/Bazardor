# 🛒 বাজার দর (BazarDor) — নিত্যপ্রয়োজনীয় পণ্যের বাজারদর

> **বাজার দর (BazarDor)** হলো বাংলাদেশের বিভিন্ন বাজারের নিত্যপ্রয়োজনীয় পণ্যসামগ্রীর (চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম, মসলা ইত্যাদি) সঠিক ও নির্ভরযোগ্য দৈনিক বাজারদর পর্যবেক্ষণের একটি আধুনিক ওয়েব অ্যাপ্লিকেশন।

## 🌐 Live Demo

🔗 **Live Website:** [https://bazardor-iota.vercel.app/](https://bazardor-iota.vercel.app/)

## 📌 প্রকল্পের বিবরণ (Project Overview)

বাজার দর অ্যাপ্লিকেশনের মাধ্যমে সাধারণ ক্রেতা এবং বিক্রেতারা প্রতিদিনের পণ্যের বাজারদর এক নজরে দেখতে পারবেন। কোন পণ্যের দাম কতটুকু বৃদ্ধি বা হ্রাস পেয়েছে, বিভাগীয় ও স্থানীয় বিভিন্ন বাজারের মধ্যে দামের তারতম্য কত, সর্বনিম্ন ও সর্বোচ্চ দর কত — সব তথ্য সহজেই খুঁজে পাওয়া যায়।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

### ১. লাইভ প্রাইস টিকার (Live Infinite Marquee Price Ticker)
- স্ক্রিনের শীর্ষে স্বয়ংক্রিয়ভাবে চলমান ইনফিনিট প্রাইস টিকার স্ট্রিপ, যেখানে প্রতিটি পণ্যের আইকন, নাম, একক প্রতি আজকের দাম এবং পরিবর্তনের শতকরা হার (▲ বৃদ্ধি / ▼ হ্রাস) রিয়েল-টাইমে প্রদর্শিত হয়।

### ২. “আজ দাম বেড়েছে” ও “আজ দাম কমেছে” সেকশন
- দৈনন্দিন বাজার পরিবর্তনের শীর্ষ ৬টি মূল্যবৃদ্ধিকৃত পণ্য (Top Risers) এবং শীর্ষ ৬টি মূল্যহ্রাসকৃত পণ্য (Top Fallers) আলাদা কার্ড গ্রিডে রঙিন ব্যাজ সহ হাইলাইট করা।

### ৩. বাজারভিত্তিক বিস্তারিত দর ও পরিসংখ্যান (Market-wise Price Breakdown)
- প্রতিটি পণ্যের একক পৃষ্ঠা (Protected Product Details Page) যেখানে দেশের প্রধান প্রধান বাজারের (যেমন: কারওয়ান বাজার, গ্রীন মার্কেট, চকবাজার ইত্যাদি) সর্বনিম্ন, গড় এবং সর্বোচ্চ দামের তুলনামূলক টেবিল এবং কার্ড মেট্রিক প্রদর্শিত হয়।

### ৪. বাংলা নিউমেরাল সহ নিখুঁত সর্টিং ও ক্যাটাগরি ফিল্টারিং
- ক্যাটাগরি অনুযায়ী ফিল্টার করার সুবিধা এবং ড্রপডাউনের মাধ্যমে “ডিফল্ট”, “দাম: কম থেকে বেশি” ও “দাম: বেশি থেকে কম” ক্রমানুসারে নিখুঁতভাবে পণ্য সাজানোর সুবিধা (Bengali Numerals Handling)।

### ৫. ইউজার অথেনটিকেশন ও প্রোফাইল আপডেট (Auth & Profile Update)
- ইমেইল/পাসওয়ার্ড এবং সোশ্যাল লগইন (Google & GitHub) সুবিধা।
- সুরক্ষিত রুট (Protected Routes) যা অননুমোদিত ব্যবহারকারীদের স্বয়ংক্রিয়ভাবে সাইন ইন পেজে যাওয়ার নির্দেশনা দেয়।
- ব্যবহারকারীর প্রোফাইল তথ্য এবং নাম পরিবর্তনের ডেডিকেটেড আপডেট রুট (`/profile/update`)।

### ৬. শতভাগ রেসপন্সিভ ডিজাইন ও কাস্টম ৪০৪ ফলব্যাক
- মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসেই চমৎকার ইউজার ইন্টারফেস।
- ভুল ইউআরএল বা অস্তিত্বহীন পণ্যের জন্য বাংলায় স্বজ্ঞাত ৪০৪ পেজ ও হোম পেজে ফিরে যাওয়ার বোতাম।
- সার্ভার ও ক্লায়েন্ট ফেইলওভার সহ অফলাইন রেজিলিয়েন্ট ডেটাস্টোর সাপোর্ট।

## 🚀 কীভাবে লোকাল কম্পিউটারে রান করবেন (Getting Started)

### ১. ডিপোজিটরি ক্লোন করুন
```bash
git clone <repository-url>
cd bazardor
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে অ্যাপ্লিকেশনটি দেখুন।

### ৪. প্রডাকশন বিল্ড তৈরি করুন
```bash
npm run build
npm start
```

## 📡 এপিআই এন্ডপয়েন্টস (API Endpoints Reference)

- **সব পণ্য (All Products):** `GET /products`
- **ক্যাটাগরি ফিল্টার (Filter by Category):** `GET /products?category=chal`
- **একক পণ্য (Single Product):** `GET /products/1` বা `GET /products/sorno-machi-chal`
- **সব ক্যাটাগরি (All Categories):** `GET /categories`
- **একক ক্যাটাগরি (Single Category):** `GET /categories/chal`
